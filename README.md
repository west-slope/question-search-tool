# 通用题库速查

导入自己的题库后，粘贴题目文字或截图，就能查到匹配的原题、答案和出处。多份题库可以一起查询。

[打开网页版](https://west-slope.github.io/question-search-tool/)

## 快速开始

1. 用 Chrome 或 Edge 打开网页，点 **添加题库文件**，或直接把文件拖进页面。可以一次选多份，也可以随时追加。
2. 确认导入区显示文件名和题量。在查询框粘贴题干、带选项的整题，或输入几个有辨识度的关键词。
3. 查看答案和出处。找到多道相近的题时，点候选题核对原题和选项。暂时用不到的题库，可以在文件名旁单独点 **移除**。

查询以题干为主，标点、空格、题号和少量缺字、多字通常不会影响查找。选项用于区分题干相近的候选。粘贴的选项齐全且能一一对应时，网页也可以按粘贴顺序换算答案字母。

### 用截图查题

先导入题库，再在网页上按 **Ctrl + V** 粘贴截图，也可以拖入图片，或点 **选择截图**。支持 PNG、JPG 和 WebP。网页识别出文字后会自动查询，识别结果会保留在输入框里，可以修改后重查。

第一次使用会加载中英文识别模型。截图尽量只包含一道题，字迹清晰时更容易识别。两道题的题干很像时，可以把选项也截进去。

## 题库文件格式

| 文件 | 可以识别的排版 |
| --- | --- |
| `.xlsx`、`.csv`、`.tsv` | 带题干和答案列的表格。XLSX 可以包含多张工作表 |
| `.docx` | 带答案的正文题目，或带题干和答案列的 Word 表格 |
| `.md`、`.markdown` | 编号题目、勾选项、明确的答案行，或 Markdown 表格 |
| `.txt` | 带答案行、勾选标记或编号答案汇总的纯文本题库。支持 UTF-8、带 BOM 的 UTF-16 和 GB18030 |
| `.pdf` | 优先读取文字层。扫描页会尝试识别，结果会显示题目所在页 |

单个文件或截图的大小上限为 16 MB。每道可查询的题都需要有明确答案。遇到格式无法识别或缺答案的文件，导入区会显示提示，同批其他可读文件仍可导入。

### 表格示例

第一行写列名，**题干**和**答案**必填，**序号**、**题型**和选项列可按需添加。`题目`、`正确答案`、`参考答案` 等常见列名也可以。选项可以分成 `选项A`、`选项B` 等列，也可以集中在一个 `选项` 列，每个选项另起一行。

| 序号 | 题干 | 题型 | 选项A | 选项B | 选项C | 答案 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 下列哪些是哺乳动物？ | 多选题 | 海豚 | 鲨鱼 | 鲸鱼 | AC |
| 2 | 正常情况下，光可以在真空中传播。 | 判断题 | | | | 正确 |
| 3 | 一个小时有多少分钟？ | 简答题 | | | | 60 分钟 |

下面的 Markdown 表格可以保存为 `.md` 后导入。

```markdown
| 题干 | 选项A | 选项B | 答案 |
| --- | --- | --- | --- |
| 地球的天然卫星是什么？ | 月球 | 火星 | A |
```

### 正文示例

下面的写法适用于 TXT、Markdown，也可以逐行写进 Word 正文。单选可写 `答案：B`，多选可写 `答案：AC`，判断和简答可直接写文字答案。

```text
1. 哪一种图形有三条边？
A. 圆形
B. 三角形
C. 正方形
答案：B

2. 一小时有多少分钟？
答案：60 分钟
```

用勾选标记表示答案的题库，可以保留原有标记。下面的题用 `(x)` 标出正确选项。

```text
# 一、单选题

+2
一天有多少小时？
( ) 12 小时
(x) 24 小时
( ) 48 小时
```

多选题也可以使用 `[x]` 标出正确选项、`[ ]` 标出其余选项。把答案集中放在末尾时，可用 `答案汇总` 作标题，并按题号写成 `1. B  2. AC`。题号应在文件内保持唯一，方便答案对应到原题。

### PDF 导入与识别

PDF 也从 **添加题库文件** 导入。有文字层的 PDF 会直接读取文字。扫描页会尝试识别，页数多时需要等待。扫描模糊、版面复杂或答案标记不清晰时，可能只能导入部分题目。加密 PDF 请先解锁再导入。

如果扫描件无法稳定读取，可以从原始 Word 或 Excel 文件导出题库，或复制带答案的文字保存为 TXT。

## 常见问题

| 情况 | 可以这样处理 |
| --- | --- |
| 只看到相近题，没看到想找的题 | 多粘贴一些题干，或把选项一起带上。也可以点候选列表中的题，查看原文和来源 |
| 截图读错了字 | 在输入框直接修正。整页截图可以先裁剪，只保留当前题 |
| 文件导入后题量偏少 | 检查表头、答案列或正文里的 `答案：`、勾选标记。PDF 可以查看是否有未读出文字的页面 |
| 刷新后或换电脑找不到原题库 | 浏览器能保存时，题库会留在当前网页和浏览器中。更换浏览器、改用离线入口或清理站点数据后，重新导入原文件即可 |

题库、截图和 PDF 在浏览器内处理，文件内容不会上传。截图和 PDF 功能需要从站点加载组件。只做文字查询时，可以下载仓库里的 [`index.html`](index.html)，用 Chrome 或 Edge 打开，并导入非 PDF 格式的题库。

## 项目文件与浏览器组件

- `index.html` 是网页入口，包含导入、匹配和界面逻辑。仓库使用 GitHub Pages 从 `main` 分支根目录发布。
- `ocr/` 包含 [Tesseract.js 6.0.1](https://github.com/naptha/tesseract.js/releases/tag/v6.0.1)、[Tesseract.js Core 6.0.0](https://github.com/naptha/tesseract.js-core)，以及来自 [Tessdata](https://github.com/naptha/tessdata) `4.0.0_best_int` 的简体中文和英语模型。
- `pdf/` 包含 [Mozilla PDF.js 6.5.438](https://github.com/mozilla/pdf.js)。相关许可证随组件文件分发。
